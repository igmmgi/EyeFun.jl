EyeFun.baseline_correct_pupil! Method
julia
baseline_correct_pupil!(df::EyeData; eye=:auto, window=(-200, 0),
                        method=:subtractive, group_by=:auto)

Baseline-correct the pupil signal for each group (e.g. each trial).

Finds all pupil samples where relative time falls within window (default: -200 ms to 0 ms; also accepts per-trial column symbol tuples such as (:baseline_start, :baseline_end)) and uses them as the baseline reference. Uses :time_rel when available, falling back to time .- time[1] within each group.

Methods

  • :subtractive: corrected = raw - mean(baseline) (arbitrary units)

  • :percent: corrected = (raw - mean(baseline)) / mean(baseline) × 100 (% change)

  • :zscore: corrected = (raw - mean(baseline)) / std(baseline) (standard deviations)

EyeFun.cluster_permutation_test Method
julia
cluster_permutation_test(df::DataFrame; value_col=:value, time_col=:time_bin,
                         condition_col=:condition, subject_col=:participant,
                         n_permutations=1000, threshold_p=0.05,
                         threshold_t=nothing, paired=true, rng=nothing) -> DataFrame

Run a Maris & Oostenveld (2007) cluster-based permutation test across time bins to control the family-wise error rate (FWER) when comparing two conditions on pupil or Visual World time-course data (e.g. from time_bin, proportion_of_looks, or empirical_logit).

Aggregates observations within (subject_col, condition_col, time_col) cells first, computes pointwise t-statistics (level1 - level2), groups contiguous supra-threshold time bins into clusters, and evaluates exact Monte Carlo cluster-mass p-values across n_permutations sign-flips (paired=true) or label shuffles (paired=false).

Returns a DataFrame with columns: cluster_id, t_start, t_end, n_bins, direction, cluster_mass, peak_t, p_value.

EyeFun.correct_pupil_foreshortening! Method
julia
correct_pupil_foreshortening!(df::EyeData; eye=:auto, camera_pos=nothing,
                              measure=:auto) -> EyeData

Apply geometric pupil foreshortening error (PFE) correction (Brisson et al., 2013; Hayes & Petrov, 2016) based on the 3D angle α between the eye-to-gaze vector and the eye-to-camera axis.

When the eye rotates off-axis by angle α, the circular pupil projects as an ellipse whose apparent area scales by cos(α). Depending on measure:

  • :area: multiplies pupil values by 1 / cos(α) (default for EyeLink/SMI area data)

  • :diameter: multiplies pupil values by 1 / sqrt(cos(α)) (default when df.source == :tobii)

  • :auto: selects :diameter for :tobii and :area otherwise

camera_pos specifies the camera position (cam_x_cm, cam_y_cm) (or 3D (cam_x_cm, cam_y_cm, cam_z_cm)) in physical centimeters relative to screen center; defaults to (0.0, 0.0, df.viewing_distance_cm) (optical axis aligned with screen center). Modifies df in-place and returns df.

EyeFun.create_eyefun_data Method
julia
create_eyefun_data(edf::EDFFile; include_variables=true, trial_time_zero=nothing,
                   screen_res=nothing, screen_width_cm=nothing, viewing_distance_cm=nothing,
                   eye=:auto) -> EyeData

Construct an EyeData container from an EDFFile (returned by read_eyelink).

Joins tracker-native fixation, saccade, blink, and message events onto the sample timeline. Each sample row is annotated with event membership (in_fix, in_sacc, in_blink) and event attributes (fix_gavx, sacc_gstx, etc.). In binocular recordings, events are stamped from the eye selected by eye (:auto picks the eye with more valid gaze samples, tie-breaking to :left).

Keyword Arguments

  • include_variables=true: join !V TRIAL_VAR messages as extra columns

  • trial_time_zero=nothing: message string that marks t=0 within each trial; when set, a time_rel column (ms relative to that message) is added

  • screen_res=nothing: override screen resolution; auto-detected from DISPLAY_COORDS / GAZE_COORDS message if nothing

  • screen_width_cm=nothing: override physical screen width in cm

  • viewing_distance_cm=nothing: override eye-to-screen distance in cm

  • eye=:auto: target eye (:auto, :left, or :right) for stamping tracker-native events

Example

julia
raw = read_eyelink("session.edf")
ed  = EyeData(raw)          # uses tracker-native events
fixations(ed)
saccades(ed)
blinks(ed)

EyeFun.detect_events! Method
julia
detect_events!(df::EyeData; method=:ivt, eye=:auto, ...)

Detect fixations and saccades using velocity-based (I-VT) or dispersion-based (I-DT) algorithms. Writes event columns directly into the DataFrame using the standard EyeFun column schema (in_fix, fix_gavx, in_sacc, sacc_gstx, etc.).

By default, overwrites existing event columns. Use prefix=:ivt to write to prefixed columns instead (e.g. ivt_in_fix), preserving originals for comparison. Detection is isolated within contiguous (participant, trial) segments so events never bleed across trial or participant boundaries.

Keyword Arguments

  • method=:ivt: Detection algorithm (:ivt for velocity threshold or :idt for dispersion threshold)

  • eye=:auto: Eye to analyze (:auto, :left, :right, or :both)

  • velocity_threshold=30.0: Velocity threshold in °/s, or :adaptive for iterative Nyström & Holmqvist (2010) data-driven threshold estimation (I-VT only)

  • dispersion_threshold=1.0: Spatial dispersion threshold in ° (I-DT only)

  • min_fixation_ms=60: Minimum fixation duration in ms

  • min_saccade_ms=10: Minimum saccade duration in ms

  • min_blink_ms=80: Minimum NaN-run duration to classify as a blink

  • detect_blinks=nothing: When true, detect blinks from NaN runs; when nothing (default), enabled automatically for :smi/:tobii data and :generic data lacking a blink column

  • refine_saccades=(velocity_threshold === :adaptive): Expand suprathreshold saccade peaks backward/forward to Nyström & Holmqvist (2010) μ + 3σ local velocity minima (I-VT only)

  • detect_pso=false: Detect post-saccadic oscillations / glissades immediately following saccade offset and populate in_pso and pso_dur columns so PSO wobble is excluded from fixation centroids (I-VT only)

  • max_pso_ms=40: Maximum post-saccadic oscillation window in ms when detect_pso=true

  • pixels_per_degree=nothing: Override automatic ppd calculation

  • prefix=nothing: nothing overwrites base columns; :ivt/:idt writes prefixed columns

EyeFun.drift_correct! Method
julia
drift_correct!(df::EyeData; target=nothing, eye=:auto,
               use_first_fixation=true, method=nothing,
               window_ms=200, group_by=:auto, prefix=nothing)

Apply drift correction by computing the gaze offset from a known fixation target at the start of each group and subtracting it from gaze, fixation, and saccade coordinates.

Keyword Arguments

  • target: expected fixation position (x, y) (default: nothing, resolving to screen center (screen_res[1] / 2, screen_res[2] / 2) in pixels or (0.0, 0.0) in centered space)

  • use_first_fixation: if true (default), uses the first fixation's center (requires fix_gavx/fix_gavy columns from event detection). If false, uses the mean gaze position in window_ms.

  • method: optional :first_fixation or :window alias overriding use_first_fixation

  • window_ms: duration of the averaging window in ms (Real, default 200) or trial-relative (t_start_ms, t_end_ms) tuple

  • group_by: grouping column(s) for per-trial correction (default: :auto, resolving to [:participant, :trial] for multi-participant data or [:trial] otherwise)

  • prefix: optional event column prefix (e.g. :ivt)

EyeFun.interpolate_blinks! Method
julia
interpolate_blinks!(df::EyeData; eye=:auto, margin_ms=50, method=:linear)

Replace pupil values during blinks (plus a margin before/after) with interpolated values within each (participant, trial) segment. Modifies the DataFrame in-place.

pupil_filter!(df::EyeData; eye=:auto, mad_multiplier=16.0, margin_ms=50,
              max_interp_ms=0, min_pupil=0.0) -> Int

Detect and remove pupil-size artifacts within each (participant, trial) segment using the Kret & Sjak-Shie (2019) Median Absolute Deviation (MAD) dilation-speed criterion plus edge-artifact padding around blink/dropout boundaries.
